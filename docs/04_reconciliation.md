# 4. Сверки: «где Ozon удерживает лишнее»

Сверка — это не разовая акция, а ежедневная витрина с допусками и владельцем действия.

| Сверка | Как считается | Допуск | Действие при расхождении |
|---|---|---|---|
| **Баланс остатков на складах Ozon** | остаток(вчера) + приёмка + возвраты в сток − отгрузки = остаток(сегодня); необъяснённое уменьшение → утрата | 0 шт. по SKU × кластер × день (в проде — небольшой допуск на сдвиг дат) | Оценка по формуле лимита возмещения, сравнение с полученным, претензия |
| **Приёмка поставок** | отгружено с ФФ vs принято Ozon по каждой поставке | 0 шт. | Акт расхождений, претензия; пересорт — проверка штрихкодов |
| **Отчёт о реализации vs API** | штуки и суммы продаж/возвратов по SKU × месяц | 0 шт., 1 ₽ | Разбор по отправлениям, запрос в поддержку |
| **Реклама: финансы vs Performance API** | списания в финансах vs расходы кампаний по дням | 2% | Найти дни/кампании без данных, дозагрузить |
| **Начисления: компоненты vs итог** | сумма строк по `type_id` vs `total_amount` | 0,01 ₽ | Нераспределённый остаток — отдельной статьёй, разбор вручную |
| **Новые статьи** | `type_id`, которого нет в маппинге | — | Добавить в справочник, решить статью P&L |
| **Выкупленные отправления без выручки** | отправление выкуплено, начисления нет | 0 | Проверить задержку начисления или потерю данных |
| **Остатки Ozon vs ФФ vs закупки** (в проде) | закуплено − на ФФ − в пути − на Ozon − продано − списано | по модели | Инвентаризация, поиск потерь на стороне ФФ |

## Возмещение за утраченный товар — как считать «сколько положено»

С 13 октября 2026 года Ozon прекратил программу страхования от массовых повреждений и атак БПЛА.
Возмещение теперь — по договору и только при вине площадки, по формуле:

```
Лимит = Действительная стоимость × Коэффициент возмещения / (1 + НДС из карточки)
Действительная стоимость: средняя цена продажи за 7 дней → за 30 дней → за 90 дней →
для неликвида — меньшая из цены других продавцов и нормативной стоимости.
Если указана «объявленная стоимость» — возмещение равно ей, но не выше лимита.
```

Отсюда три практических вывода, которые витрина учитывает:

1. **Ставка НДС в карточке напрямую меняет возмещение** — проверяем справочник на корректность.
2. **Чем дольше товар лежит, тем меньше возмещение** — это ещё один аргумент за частые поставки
   малыми партиями (Ozon сам рекомендует запас на 1–2 недели).
3. **Документы собираются до события, а не после**: ежедневные снимки остатков по складам —
   доказательная база, если товар пропадёт.

## Инструменты закона о платформенной экономике

По обзору «Сравни» (сентябрь 2026), с 1 октября 2026 года продавец может запросить акт сверки
в любой момент — площадка обязана предоставить его в течение семи рабочих дней; об ухудшении
условий площадка предупреждает за 45 дней. Ежемесячный акт сверки становится частью регламента:
витрина сверяет его с начислениями API.
